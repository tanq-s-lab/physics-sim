静止摩擦力と動摩擦力

静止: f = F ≦ μN すべる: f = μ'N

    引く力 F と 摩擦力 f の関係

    • 摩擦力 f(これまでの記録)
    • 最大摩擦力 μN・動摩擦力 μ'N

    力の時間変化

    • 引く力 F(ばねばかりの読み)
    • 摩擦力 f
    • 動き出した瞬間
    速さ
    最大摩擦力に達したら

    「ゆっくり引く」で F が毎秒 1 N ずつ増えます。摩擦力が最大摩擦力 μN に達した瞬間、すべり出す直前で止まります(「止めたまま」なら「再開」で続きを見ます)。ばねばかり(右の手)をドラッグして自分で引くこともできます。すべり出したあと「等速で引く」を押すと、F = μ'N にして一定の速さで引きます。

    ポイント

    • 止まっている間は、静止摩擦力 f は引く力 F と同じ大きさ(つりあい)。F を大きくすると f も大きくなります。グラフでは傾き 1 の直線。
    • 静止摩擦力には限界があり、これが最大摩擦力 μN。F が μN を超えた瞬間に箱はすべり出します。
    • すべっている間は動摩擦力 μ'N。F をさらに大きくしても一定で、速さによりません。
    • ふつう μ' < μ なので、動き出した瞬間に摩擦力がガクッと下がります。「動かし始めが一番重い」のはこのため。
    • F > μ'N の間は加速度 a = (F − μ'N)/m で速くなり、F = μ'N にすると等速、F < μ'N にすると減速して止まります。
    • 水平な床では N = mg。μN も μ'N も、質量 m に比例します。

    考えてみよう

    1. m = 2.0 kg、μ = 0.50 のとき、何 N で引くと動き出す? 計算してから「ゆっくり引く」で確かめよう。
    2. F を 4 N にして止めたとき、摩擦力はいくら? 「最大摩擦力 9.8 N」と答えるのはなぜまちがい?
    3. すべっている箱を、F = μ'N で引き続けると箱はどうなる? 「等速で引く」で確かめ、つりあいで説明しよう。
    4. すべっている途中で F を 0 にすると、箱は何秒で止まる? μ' と g だけで表してみよう。
    5. 質量を 2 倍にすると、「F と f の関係」のグラフの形はどう変わる?
