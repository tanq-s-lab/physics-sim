2つの点電荷と電位の谷

V = kQ₁/r₁ + kQ₂/r₂, W = qΔV
xy 平面(等電位線)
縦軸: x 軸上の電位 V [kQ/a]
記録
  • V＞0
  • V＜0
  • V = 0 の等電位線
  • 静電気力
  • 速度
  • 全エネルギー qV(x₀)

    ① −Q を (−3a, 0) まで運ぶ

    電気量 −Q の小球を、負の無限遠から点 (−3a, 0) までゆっくり運ぶ。静電気力がする仕事は? 図の左端を「無限遠」の代わりにし、W は無限遠からの値 W = (−Q)(0 − V) = Q·V(x) を表示します。

    答えを確かめる(+Q, −4Q のとき)

    V(−3a) = kQ/(4a) − 4kQ/(2a) = −7kQ/(4a)

    W = (−Q){V(∞) − V(−3a)} = −7kQ²/(4a)(負の仕事。−Q は −4Q に押し戻されながら運ばれる)

    ② 速さが最大になる点

    正電荷の小球を (a, 0) のすぐ右に静かに置くと、x 軸正の向きに動き出す。速さが最大になるのはどこ?

    答えを確かめる(+Q, −4Q のとき)

    速さ最大 ⇔ 加速度 0 ⇔ 電場 E = 0(V(x) の谷底)。kQ/(x−a)² = 4kQ/(x+a)² より x + a = 2(x − a)

    ∴ x = 3a(δ によらない)

    ③ 無限遠に届くか

    正電荷の小球を (x₀, 0)(x₀＞a)に静かに置く。x 軸正の向きの無限遠に到達しないのは、x₀ がどんな範囲のとき?

    答えを確かめる(+Q, −4Q のとき)

    ½mv² + qV(x) = qV(x₀)。無限遠では V = 0 なので、届くには qV(x₀) ≥ 0 が必要。V(x₀) = 0 となるのは x₀ = 5a/3。

    ∴ 到達しない条件 x₀ ≥ 5a/3(x₀ = 5a/3 は無限遠でちょうど速さ 0 になる境界)

    小球は図の上でドラッグして動かせます(①と③)。上の図にカーソルを当てると、その点の電位が出ます。静電気力の矢印は、力が強いほど長くなります(長さは目安)。単位は k = a = 1、小球の質量・電気量は 1 にしています。

    ポイント

    • 2 つの点電荷がつくる電位は、それぞれの電位の和:V = kQ₁/r₁ + kQ₂/r₂(電位はスカラーなので、そのまま足せる)。
    • 静電気力がする仕事は W = q(V始 − V終)。通った道すじによらず、はじめと終わりの電位だけで決まる。
    • x 軸上の V(x) のグラフは「電位の坂道」。正電荷の小球は坂を下る向きに力を受け、グラフの傾きが −Ex。
    • V(x) の谷底は電場 E = 0 の点。加速度が 0 になるので、そこで速さが最大になる。
    • 力学的エネルギー保存 ½mv² + qV = 一定。全エネルギーの線(だいだいの破線)より V(x) が高い場所には行けない。無限遠(V = 0)に届くには qV(x₀) ≥ 0 が必要。

    考えてみよう

    1. ② で δ を変えて放してみよう。速さが最大になる位置は変わる? 最大の速さはどうなる?
    2. ③ で x₀ を V = 0 の点の左右に置いてみよう。だいだいの線と V(x) のグラフの関係から、届く・届かないを説明しよう。
    3. ③ で谷底より右に置くと、小球はどちらに動き出す? そのあとどんな運動になる?
    4. Q₂ を −9Q、−Q に変えると、E = 0 の点と V = 0 の点はどう動く? 谷底がなくなるのはどんなとき?
    5. 上の図で、谷底の点を通る等電位線はどんな形? その点で等電位線が交わるのはなぜ?
