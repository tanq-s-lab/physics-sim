定常波(定在波)のでき方

節の間隔 = λ/2 ,腹の振幅 = 2A
  • 右へ進む波 y₁
  • 左へ進む波 y₂
  • 合成波 y₁ + y₂(定常波)
  • 媒質の粒
  • 注目する粒(タップで選べる)
  • 振幅の範囲(包絡線)
    表示する波(タップでオン・オフ)
    速さ
    コマ送り
    1コマ
    t = 0
    媒質 定常波 グラフ

    図の粒をタップすると、その粒が「注目する粒」になります(節の粒・腹の粒を選んで比べてみよう)。コマ送りを押すと自動で停止します。縦(変位)の目盛りは見やすく拡大しています。

    ポイント

    • 振幅・波長・周期が同じで逆向きに進む 2 つの波が重なると、どちらにも進まない定常波(定在波)ができます。
    • まったく揺れない点が節、いちばん大きく揺れる点が腹。節と節(腹と腹)の間隔は λ/2、節と腹の間隔は λ/4。
    • 腹の振幅は元の波の 2 倍の 2A。腹と腹の間の粒は、みな同じタイミングで上下します(となりの区間とは逆向き)。
    • 式で書くと y₁ + y₂ = 2A cos(kx′)·sin ωt(x′ は真ん中の腹からの距離)。場所で決まる振幅 × 時間で振動、の形です。

    考えてみよう

    1. 1コマ T/8 でコマ送りして、合成波がまっすぐ(y = 0 の直線)になるのはいつ? そのとき y₁ と y₂ はどうなっている?
    2. 節の位置で、y₁ と y₂ はいつも「同じ大きさで逆向き」になっている。重ね合わせの矢印で確かめよう。
    3. 波長 λ を変えると、節の数と節の間隔はどう変わる?
    4. 赤い粒を節の近く・腹・その間に置いて、y–t グラフの振幅を比べよう。周期はちがう?
