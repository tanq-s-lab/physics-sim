共振回路(RLC 直列)

f0 = 1 / (2π√LC)
共振との近さ—
  • XLコイルの流れにくさ ωL(f が高いほど大)
  • XCコンデンサーの流れにくさ 1/(ωC)(f が高いほど小)
  • Z回路全体の流れにくさ(インピーダンス)
  • R電球の抵抗(Z はこれより小さくならない)
  • I0流れる電流の振幅 = V₀/Z(Z が最小のとき最大)
    ゆっくり動かす
    回転の速さ

    電源(電圧の振幅 V0 = 10 V)の周波数 f は一定のまま、L・C を動かして共振させてみよう。グラフの縦線は電源の f(ドラッグで変更)、紫の点線は回路の f0。2本が重なると共振です。電球の明るさは消費電力(共振のとき最大)。

    ポイント

    • コイルのリアクタンス XL = ωL は周波数とともに増え、コンデンサーの XC = 1/(ωC) は減る。2本のグラフの交点が共振周波数 f0。
    • XL = XC から f0 = 1/(2π√LC)。f0 を決めるのは L と C だけ(R は関係しない)。
    • インピーダンス Z = √(R² + (XL − XC)²) は共振で最小(Z = R)、電流 I0 = V0/Z は最大(V0/R)。
    • 共振では VL と VC が大きさが等しく逆向きで打ち消し合い、電源の電圧はすべて R にかかる。電流と電圧は同位相(φ = 0)。
    • 打ち消し合っているだけなので、VL・VC の一つ一つは電源の V0 よりずっと大きくなることがある。
    • R が小さいほど共振曲線のピークは高く鋭い。ラジオの選局(同調)は、可変コンデンサーで f0 を放送局の周波数に合わせる共振の利用。

    考えてみよう

    1. f = 50 Hz、L = 200 mH のとき、共振させるには C を何 μF にすればよい? 計算してから C のスライダーで確かめよう。
    2. L を 4 倍にすると f0 は何倍? グラフの交点はどう動く?
    3. R を小さくすると共振曲線はどう変わる? f0 は変わる? 「目盛りを固定」にして比べよう。
    4. 共振しているときの VL0 を読み取ろう。電源は 10 V なのに、それより大きいのはなぜ矛盾しない?
    5. f が f0 より低いとき、電圧は電流より進む? 遅れる? XL と XC のどちらが大きい?
