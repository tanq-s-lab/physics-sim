電気振動(LC 回路)

T = 2π√LC
  • qコンデンサーの上の極板の電荷(電場のエネルギー UC = q²/2C)
  • iコイルを流れる電流。放電の向き(上の極板 → コイル)を正(磁場のエネルギー UL = Li²/2)
  • 抵抗 R で熱になったエネルギー
    速さ

    はじめにコンデンサーを電池で電圧 V0 まで充電してあります。スイッチをコイル側に入れると、電荷が行ったり来たりする電気振動が始まります。実際の振動は速いので、1/50 や 1/200 のスローで見せています(グラフの時間は実際の値)。値を変えると、はじめの状態から振動し直します。

    ポイント

    • 充電したコンデンサーをコイルにつなぐと、電荷が行ったり来たりして、電流の向きが周期的に入れかわる。これが電気振動。
    • 周期は T = 2π√LC(固有周期)、振動数は f = 1/(2π√LC)。前の「共振回路」の f0 と同じ式。
    • 電荷 q が最大のとき電流 i = 0、q = 0 のとき |i| が最大。q と i は位相が π/2 ずれている。
    • エネルギーは電場(UC = q²/2C)と磁場(UL = Li²/2)の間を行き来し、R = 0 なら和は一定: Q0²/2C = LI0²/2。ここから I0 = Q0/√LC。
    • q = 0 になっても電流がすぐ止まらないのは、コイルが電流の変化を妨げる(自己誘導)から。ばね振り子でおもりが慣性でつり合いの位置を通りすぎるのと同じ。
    • 抵抗があるとエネルギーがジュール熱として失われ、振動は減衰する。
    電気振動ばね振り子
    電荷 q変位 x
    電流 i速さ v
    自己インダクタンス L質量 m(変化しにくさ)
    1/Cばね定数 k
    UC = q²/2C, UL = Li²/2kx²/2, mv²/2
    T = 2π√LCT = 2π√(m/k)

    考えてみよう

    1. C を 4 倍にすると周期 T は何倍? グラフの目盛りで確かめよう。
    2. スイッチを入れてから、電流が初めて最大になるのは何周期後? そのときコンデンサーの電荷はいくら?
    3. L = 500 mH、C = 200 μF、V0 = 6 V のとき、電流の最大値 I0 を計算しよう(エネルギー保存を使う)。
    4. 電荷 q が 0 の瞬間に、エネルギーはどこにある? 棒グラフで確かめよう。
    5. R を大きくしていくと振動はどう変わる? 失われたエネルギーはどこへ行った?
